# KB-007 — Device Troubleshooting Guide

**Article ID:** KB-007  
**Category:** Technical Support  
**Version:** 1.4  
**Effective Date:** 2023-08-01  
**Last Updated:** 2024-05-10

## Summary

Basic device-level troubleshooting for smartphones, tablets, and broadband routers. This article covers common software and configuration issues. Hardware defects are out of scope and must be referred to the customer's device manufacturer.

## Scope

This article applies to **network-related device issues** only. We do not provide support for:
- Third-party applications
- Operating system errors unrelated to connectivity
- Device hardware failures
- Screen or battery issues

## Mobile Device — Network Configuration

### Problem: No internet despite full signal

1. Check data limit: If 4G data exhausted, device may fall back to 2G (slow) or show no data.
2. Verify APN settings (see KB-003 for APN details).
3. Clear network cache: Settings → Apps → System Apps → Telephony → Clear Cache.
4. Reset network settings (note: Wi-Fi passwords will be deleted).

### Problem: Unable to make/receive calls

1. Verify account is not suspended.
2. Check device is not in Do Not Disturb or call barring mode.
3. Verify correct network mode selected (not locked to 5G in a 4G area).

### Problem: SMS not delivered

1. Verify message center number is correct (this varies by carrier and region).
2. Check device storage is not full (low storage blocks SMS on some devices).

## Router — Common Issues

### Problem: Wi-Fi password not working

1. Check Caps Lock — passwords are case-sensitive.
2. If changed recently, update all saved passwords.
3. If forgotten: Log into router admin panel (usually 192.168.1.1 or 192.168.0.1) with admin credentials.
4. Factory reset as last resort (see KB-002 Step 6).

### Problem: Slow Wi-Fi despite good broadband speed

This is usually a Wi-Fi issue, not a broadband issue.

1. Move device closer to router.
2. Use 5GHz band for better speed (shorter range but faster).
3. Check for interference from microwaves, cordless phones.
4. Check how many devices are connected — heavy use degrades Wi-Fi.
5. Restart router (see KB-002 Step 2).

## Important Limitation

**We cannot guarantee compatibility with all third-party routers.** If a customer uses a self-purchased router (not our provided equipment), troubleshooting support is limited to connection point only (ONT or modem output). Configuration of third-party routers is not supported.

## Escalation Criteria

- Potential device hardware defect (advise customer to contact device manufacturer).
- Router provided by us showing hardware fault (lights indicating hardware failure, physical damage).
- Customer-provided router shows persistent connection issues that the ONT side tests as healthy.
